    ObjectIO¶

    Software-defined storage in Rust: an S3-compatible object store on an erasure-coded, topology-aware storage core, with data-lake catalogs and block volumes built on the same core. Source on GitHub.

    ObjectIO is pre-1.0. Pick the version you run with the selector at the top; dev follows the main branch.

    • Roadmap: every feature, its status, and the milestones ahead.
    • Operations guide: installing, administering and running a cluster.
    • Developer guide: the S3, Iceberg, Unity Catalog, Delta Sharing and admin APIs; S3 compatibility runs.

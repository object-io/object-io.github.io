    Metrics reference¶

    Every Prometheus metric ObjectIO exports: where it comes from, what it means, and the alerts worth setting on it. For dashboards, Prometheus setup and the console's views of these metrics, see Monitoring.

    All metrics are plain Prometheus text exposition. Names start with objectio_ (and process_ for the standard process family).

    Where to scrape¶

    Process Endpoint Notes
    Gateway :9000/metrics Or the --admin-listen address when the admin surface is split off.
    Meta :9101/metrics --metrics-port; 0 serves none.
    OSD :9201/metrics --metrics-port; 0 serves none.
    Block gateway :9301/metrics --metrics-listen; empty serves none.

    One gateway (and aio): scrape the gateway alone. By default the gateway polls every OSD and meta node every 30 seconds and re-exports their metrics on its own /metrics. Re-exported OSD series carry an osd_id label, and meta series carry component="meta". The all-in-one binary runs meta, the OSDs and the block gateway in one process with their own ports off, so the gateway's /metrics is the only endpoint and carries everything.

    Several gateways (the helm chart): scrape every process directly. Run gateways with --no-reexport-metrics (the chart does, via gateway.reexportMetrics: false). Otherwise each gateway exports a copy of every OSD's and meta's metrics, and every sum multiplies by the number of gateways. The chart's Prometheus scrapes meta on 9101 and the OSDs on 9201 directly.

    Do not do both. Scraping a re-exporting gateway and the OSDs and meta directly counts every OSD and meta series twice.

    Series the gateway derives from its own poll (objectio_cluster_*, objectio_osd_capacity_bytes, the usage and data-safety families) exist once per gateway. With several gateways, aggregate them with max, not sum.

    Conventions¶

    • Latency is a histogram, in seconds, with buckets from 1 ms to 10 s (or wider where noted). Take percentiles with histogram_quantile(0.99, sum by (le) (rate(<name>_bucket[5m]))), and keep le in any sum by.
    • Counters reset when a process restarts. Use rate() or increase(), which handle resets.
    • A family can be absent. Counter and histogram families appear once something has been recorded. SMART families need smartctl on the host. Iceberg, Unity, lifecycle and drain families need those features in use. Absent is not the same as zero.
    • Label cardinality is bounded. Operations, methods, codes and reasons come from fixed sets. Per-bucket usage (objectio_bucket_*) is one series per bucket; leave it out with --no-bucket-metrics past tens of thousands of buckets. Per-volume and per-snapshot series are one per volume and snapshot.
    • gRPC status codes use gRPC's names (OK, NOT_FOUND, UNAVAILABLE…). A streaming call that fails part-way counts as OK; its status arrives after the response headers, where it is measured.

    Alerts worth setting¶

    These are starting points; tune thresholds to the hardware and workload.

    groups:
  - name: objectio
    rules:
      # Data safety
      - alert: ObjectsUnreadable
        expr: max(objectio_objects_unreadable) > 0
        labels: {severity: critical}
        annotations:
          summary: Objects have fewer than k readable shards
      - alert: ObjectsAtRisk
        expr: max(objectio_objects_at_risk) > 0
        for: 15m
        labels: {severity: warning}
        annotations:
          summary: Objects are one failure from unreadable and not yet repaired
      - alert: UnrecoverableStripes
        expr: increase(objectio_meta_repair_unrecoverable_stripes_total[1h]) > 0
        labels: {severity: critical}
      - alert: RepairNotRunning
        expr: time() - max(objectio_meta_repair_last_pass_timestamp_seconds) > 3600
        labels: {severity: warning}
        annotations:
          summary: No repair pass completed in an hour
      - alert: ScrubStale
        expr: time() - min(objectio_osd_scrub_last_pass_timestamp_seconds) > 7 * 86400
        labels: {severity: warning}
      - alert: CorruptShards
        expr: sum(objectio_osd_corrupt_shards) > 0
        for: 1h
        labels: {severity: warning}
        annotations:
          summary: Corrupt shards found and not rebuilt within an hour

      # Metadata
      - alert: MetaNoLeader
        expr: max(objectio_meta_raft_has_leader) == 0
        for: 1m
        labels: {severity: critical}
        annotations:
          summary: Meta has no Raft leader; no metadata write can commit
      - alert: MetaElectionsChurn
        expr: increase(max(objectio_meta_raft_term)[15m:]) > 3
        labels: {severity: warning}
      - alert: MetaFollowerLagging
        expr: max(objectio_meta_raft_replication_lag_entries) > 1000
        for: 5m
        labels: {severity: warning}

      # Capacity
      - alert: ClusterFilling
        expr: max(objectio_cluster_used_bytes) / max(objectio_cluster_capacity_bytes) > 0.8
        labels: {severity: warning}
      - alert: OsdDown
        expr: max(objectio_cluster_osds_total) - max(objectio_cluster_osds_up) > 0
        for: 5m
        labels: {severity: warning}

      # Durability latency
      - alert: SlowShardSync
        expr: histogram_quantile(0.99, sum by (le) (rate(objectio_osd_disk_seconds_bucket{op="sync"}[5m]))) > 0.1
        for: 10m
        labels: {severity: warning}
      - alert: SlowBlockJournal
        expr: histogram_quantile(0.99, sum by (le) (rate(objectio_block_journal_fsync_seconds_bucket[5m]))) > 0.05
        for: 10m
        labels: {severity: warning}
        annotations:
          summary: Every block write waits for this fsync

      # Block storage
      - alert: BlockFlushFailing
        expr: rate(objectio_block_chunks_flushed_total{result="failed"}[10m]) > 0
        for: 10m
        labels: {severity: warning}
        annotations:
          summary: Chunks are not being stored; writes stay journaled and the cache fills
      - alert: BlockReadErrors
        expr: rate(objectio_block_io_errors_total{op="read"}[5m]) > 0
        labels: {severity: critical}

      # Requests
      - alert: S3ServerErrors
        expr: sum(rate(objectio_s3_requests_total{status="server_error"}[5m])) / sum(rate(objectio_s3_requests_total[5m])) > 0.01
        for: 10m
        labels: {severity: warning}
      - alert: SpaceLeaking
        expr: increase(objectio_gateway_shard_reclaim_failures_total[1h]) + increase(objectio_block_shard_delete_failures_total[1h]) > 100
        labels: {severity: info}
        annotations:
          summary: Shard deletes failing; space stays allocated

    Known gaps¶

    • Gateway to meta calls are measured only on meta's side (objectio_meta_grpc_latency_seconds), which leaves out network time.
    • Lifecycle expiry deletes an object's metadata but not its shards (a known leak); objectio_lifecycle_actions_total{action="expire"} counts the deletes, and the space they leave is not reclaimed yet.
    • The Transfer Engine (RDMA) path reports transfers and fallbacks, but not its own latency.
    • Tracing (OpenTelemetry spans across gateway, meta and OSD) is not implemented.

    CLI (obioctl)¶

    obioctl manages a cluster through the gateway's admin API, signed with SigV4 like the SDKs. Every command goes through the same authentication, tenant scoping, validation, Block Public Access and audit as any other caller. It never talks to meta directly, so meta's ports can stay closed to everything but the cluster.

    Bucket lifecycle, CORS and bucket-level public access block are S3 calls, signed the same way. sts assume-role-with-web-identity needs no key. volume and snapshot talk to the block gateway (--block-endpoint, default http://localhost:9300).

    Configure¶

    obioctl configure                 # prompts for endpoint, key and secret
obioctl --profile acme configure --endpoint https://s3.example.com \
  --access-key AKIA… --secret-key … --non-interactive
obioctl configure --list          # secrets masked

    Profiles live in ~/.objectio/config (mode 0600). Settings are resolved in this order: 1. flags (--endpoint, --access-key/--secret-key, --region); 2. --profile; 3. the environment, as the SDKs read it: OBJECTIO_ENDPOINT, OBJECTIO_ACCESS_KEY(_FILE), OBJECTIO_SECRET_KEY(_FILE), with the AWS_* names as fallbacks; 4. the OBJECTIO_PROFILE or default profile.

    The key must be unscoped: a key confined to a bucket is refused on the admin API. The system admin and tenant admins use the same CLI; without --tenant, a command acts in the caller's own tenant.

    Output¶

    Tables by default. -o json prints the API's JSON for scripting:

    obioctl -o json user create alice | jq -r .user_id

    On error the exit code is non-zero and stderr carries the server's message. A secret is printed only when it's created.

    cluster info, topology, usage, drain-status, validate-placement, rebalance status\|pause\|resume

    obioctl <group> --help lists each command's options. The source tree has the full command → API route map in bin/cli/README.md.

    Examples¶

    Onboard a tenant, as the system admin:

    obioctl tenant create acme --display-name "Acme" --quota-bytes 2T --default-pool standard
ADMIN=$(obioctl -o json user create acme-admin --tenant acme | jq -r .user_id)
obioctl tenant admin add acme "$ADMIN"
obioctl key create "$ADMIN"          # hand this to acme's admin

    As acme's admin:

    obioctl user create alice
obioctl policy create read-logs --file read-logs.json
obioctl policy attach read-logs --user <alice-id>
obioctl public-access-block put --all
obioctl bucket create logs
obioctl bucket lifecycle put logs --file lifecycle.xml

    Take an OSD out of service:

    obioctl osd set-state <osd-id> draining
obioctl cluster drain-status

    Temporary credentials from a CI job's OIDC token:

    eval "$(obioctl sts assume-role-with-web-identity \
  --role-arn arn:obio:iam::acme:role/ci --token-file "$TOKEN_FILE" --env)"

    Configuration Reference¶

    ObjectIO binaries are configured via CLI flags, a small set of environment variables, and an optional TOML file. Flags win over env vars, env vars win over the TOML file, the TOML file wins over built-in defaults.

    This page documents the flag surface for each binary against the current main. It is authoritative over the compose files in deploy/ — some of those files set env vars (OBJECTIO_BIND, OBJECTIO_NODE_ID, etc.) that the binaries do not actually read. Only the env vars listed below are honoured.

    Ports — cluster conventions vs code defaults¶

    There are two port conventions in the repo. Most deployments follow the cluster convention (used by the Helm chart and the compose files). The CLI flags' code defaults are different:

    Role Cluster port Code default Protocol
    gateway S3 9000 9000 HTTP
    meta gRPC 9100 9001 gRPC
    meta metrics 9101 9101 HTTP
    meta admin (Raft bootstrap / membership) 9102 9102 HTTP
    OSD gRPC 9200 9002 (example config) gRPC
    OSD metrics 9201 9201 HTTP
    block-gateway gRPC 9300 9300 gRPC
    block-gateway NBD 10809 10809 TCP (NBD)

    The chart / compose values are what you should document to end users. The code defaults only matter if you run the binaries standalone with no --listen override.

    objectio-gateway¶

    S3 / Iceberg / Delta Sharing / admin / console.

    Flags¶

    objectio-gateway \
  --listen 0.0.0.0:9000 \
  --meta-endpoint http://meta1:9100,http://meta2:9100,http://meta3:9100 \
  --ec-k 4 --ec-m 2 \
  --region us-east-1
    Flag Default Purpose
    -c, --config <path> /etc/objectio/gateway.toml TOML config file
    -l, --listen <addr> 0.0.0.0:9000 Data plane listen — S3 + Iceberg + Delta Sharing. In legacy mode also serves /_admin/* and /_console/*.
    --admin-listen <addr> empty Optional dedicated listener for /_admin/* + /metrics. Set this and admin moves off --listen entirely (see Listener split).
    --ops-console-listen <addr> empty Optional dedicated listener for the ops console SPA + /_admin/* (system-admin surface).
    --tenant-console-listen <addr> empty Optional dedicated listener for the tenant console SPA + /_admin/* (end-user surface).
    --meta-endpoint <urls> http://localhost:9001 Meta nodes: one address, or every meta node's, comma-separated. Any node serves any call (a follower forwards it to the Raft leader), and one that stops answering is skipped. See Meta high availability.
    --osd-endpoint <url> http://localhost:9002 Initial OSD peer
    --ec-k <n> 4 EC data shards
    --ec-m <n> 2 EC parity shards
    --protection <kind> ec ec, lrc, or replication
    --lrc-local-parity <n> 0 LRC local parity count (with --protection=lrc)
    --lrc-global-parity <n> 0 LRC global parity count
    --replicas <n> 3 Replica count (with --protection=replication)
    --no-auth off Disable SigV4 — dev only
    --endpoint-name <name> empty Name of the --listen endpoint, seen by policies as aws:SourceVpce (see Public Access). Env OBJECTIO_ENDPOINT_NAME.
    --data-listen <addr>=<name> — A further data-plane listener (S3, Iceberg, Delta Sharing; no admin, no console) with its own endpoint name. Repeatable.
    --audit-log <path> unset Append every request's audit event as JSON lines to this file (- for stdout). Env OBJECTIO_AUDIT_LOG.
    --trusted-proxies <cidrs> empty Proxies whose X-Forwarded-For / X-Forwarded-Proto are believed for aws:SourceIp / aws:SecureTransport. Env OBJECTIO_TRUSTED_PROXIES. Set it when TLS ends at an ingress.
    --region <name> us-east-1 SigV4 verification region
    --external-endpoint <url> empty Public URL (Iceberg vended creds, Delta Sharing presign, OIDC callback)
    --master-key-env <name> OBJECTIO_MASTER_KEY Env var name holding the base64 SSE master key
    --kms-backend <kind> local local or vault
    --oidc-issuer-url <url> unset Enables OIDC login for console + Iceberg JWTs
    --oidc-client-id <id> unset OIDC client ID
    --oidc-client-secret <val> unset OIDC client secret
    --oidc-audience <val> client id JWT aud expected value
    --oidc-groups-claim <name> groups Claim mapping to group/role set
    --oidc-role-claim <name> role Claim mapping to single role
    --oidc-scopes <scopes> openid profile email Space-separated scope list
    --oidc-admin-roles <roles> empty Comma-separated list of admin-granting roles
    --delta-access-key-id <ak> empty Presign AK for Delta Sharing recipient URLs
    --delta-secret-key <sk> empty Presign SK for Delta Sharing recipient URLs
    --host-provider <kind> noop noop, k8s, linux-ssh, appliance — powers /_admin/osds/*/reboot
    --host-provider-namespace <ns> default Namespace for the k8s provider (from $POD_NAMESPACE)
    --host-provider-osd-sts <name> objectio-osd OSD StatefulSet name for the k8s provider
    --topology-region <val> empty Gateway's own topology — drives locality-aware reads
    --topology-zone <val> empty
    --topology-datacenter <val> empty
    --topology-rack <val> empty
    --topology-host <val> empty
    --log-level <lvl> info trace, debug, info, warn, error

    Environment variables¶

    The clap parser reads these directly — no wrapper needed:

    Env Flag
    OBJECTIO_TOPOLOGY_REGION --topology-region
    OBJECTIO_TOPOLOGY_ZONE --topology-zone
    OBJECTIO_TOPOLOGY_DATACENTER --topology-datacenter
    OBJECTIO_TOPOLOGY_RACK --topology-rack
    OBJECTIO_TOPOLOGY_HOST --topology-host
    OBJECTIO_HOST_PROVIDER --host-provider
    OBJECTIO_HOST_PROVIDER_OSD_STS --host-provider-osd-sts
    POD_NAMESPACE --host-provider-namespace

    Read separately from the flag surface:

    Env Purpose
    OBJECTIO_MASTER_KEY 32-byte base64 SSE-S3 master key
    OBJECTIO_CONSOLE_DIR Path to the legacy single-bundle /_console/ SPA (default /usr/share/objectio/console). In split mode used only as the base for the per-bundle defaults below.
    OBJECTIO_OPS_CONSOLE_DIR Path to the ops SPA bundle. Default: $OBJECTIO_CONSOLE_DIR/ops. Served on --ops-console-listen.
    OBJECTIO_TENANT_CONSOLE_DIR Path to the tenant SPA bundle. Default: $OBJECTIO_CONSOLE_DIR/tenant. Served on --tenant-console-listen.
    RUST_LOG Override --log-level; tracing directive syntax

    Listener split¶

    By default the gateway is a single-port deployment: --listen carries S3, Iceberg, Delta Sharing, /_admin/*, /metrics, and /_console/* all on the same socket. This matches MinIO's default and is fine for small clusters.

    For larger or regulated deployments you can split the four planes across separate listeners by setting any combination of --admin-listen, --ops-console-listen, --tenant-console-listen. Each binds independently; you can enable one, two, or all three.

    Listener Default flag Routes mounted Audience
    data --listen 0.0.0.0:9000 /, /{bucket}*, /iceberg/v1/*, /api/2.1/unity-catalog/*, /delta-sharing/v1/*, /health Public — SDK / CLI / Spark / Trino
    admin API --admin-listen 127.0.0.1:9001 /_admin/*, /metrics, /health CLI, third-party integrations (Datadog, billing, OTel)
    ops console --ops-console-listen 127.0.0.1:9002 /_console/* (ops SPA), /_console/api/*, /_admin/*, /health System operators on a mgmt VLAN
    tenant console --tenant-console-listen 0.0.0.0:9003 /_console/* (tenant SPA), /_console/api/*, /_admin/*, /health End users — safe to expose publicly

    Behavior in split mode:

    • /_admin/* is mounted on the admin API listener AND on each console listener (the browser stays same-origin — no CORS). It is removed from the data listener — /_admin/* requests there fall through the S3 wildcard and return SigV4 errors.
    • /metrics lives on the admin API listener only.
    • /_console/* is removed from the data listener; each console listener serves its own SPA bundle from OBJECTIO_OPS_CONSOLE_DIR / OBJECTIO_TENANT_CONSOLE_DIR.
    • The startup log emits a WARN if --admin-listen or --ops-console-listen is bound to 0.0.0.0 — the intent of the split is to firewall the control plane to a mgmt interface.
    • The same /_admin/* handlers run on every listener that mounts them. Per-tenant scope is enforced server-side (see require_tenant_admin_access), so the tenant console listener is not a privilege-elevation path even though it exposes the same surface as the ops console.

    Why two consoles, not one with role-gating: see architecture/console-split.

    Example — public S3 on the WAN, control plane on a mgmt VLAN:

    objectio-gateway \
  --listen                  0.0.0.0:9000 \
  --admin-listen           10.0.5.10:9001 \
  --ops-console-listen     10.0.5.10:9002 \
  --tenant-console-listen   0.0.0.0:9003 \
  --meta-endpoint http://meta1:9100 \
  --region us-east-1

    Backward compatibility: omit all three split flags and the gateway behaves exactly like pre-split deployments — single port, everything mounted. Existing Helm values and TOML configs continue to work unchanged.

    objectio-meta¶

    Raft metadata cluster.

    Flags¶

    objectio-meta \
  --node-id 1 \
  --listen 0.0.0.0:9100 \
  --peers meta1:9101,meta2:9101,meta3:9101 \
  --data-dir /var/lib/objectio/meta
    Flag Default Purpose
    -c, --config <path> /etc/objectio/meta.toml TOML config file
    --node-id <n> unset Raft node ID (required for multi-node clusters; auto-assigned for single-voter)
    -l, --listen <addr> 0.0.0.0:9001 gRPC listen — MetadataService + RaftRpc
    --peers <list> empty Comma-separated Raft peer list (host:port,...)
    --osd <list> empty Pre-register OSDs on startup (host:port repeated)
    --ec-k <n> 4 Default EC data shards
    --ec-m <n> 2 Default EC parity shards
    --replication <n> unset Use replication instead of EC (1 = single-voter dev mode)
    --data-dir <path> /var/lib/objectio/meta Persistent Raft + redb state
    --admin-user <name> admin Initial admin username (created on first startup)
    --metrics-port <n> 9101 Prometheus scrape port
    --admin-port <n> 9102 HTTP admin — Raft bootstrap + membership
    --raft-advertise <addr> empty Address advertised to Raft peers (defaults to --listen)
    --log-level <lvl> info

    --listen vs --raft-advertise: --listen is what the pod binds to locally; --raft-advertise is what it tells peers to reach it at. In Kubernetes the chart sets advertise to the pod DNS (pod-0.meta-svc.ns.svc.cluster.local).

    No --raft-bind flag exists — Raft RPC multiplexes over the same gRPC socket as MetadataService.

    TOML¶

    # /etc/objectio/meta.toml
[meta]
node_id = 1
listen = "0.0.0.0:9100"
peers = ["meta1:9101", "meta2:9101", "meta3:9101"]
data_dir = "/var/lib/objectio/meta"
ec_k = 4
ec_m = 2

[logging]
level = "info"

    objectio-osd¶

    Object Storage Daemon.

    Flags¶

    objectio-osd \
  --listen 0.0.0.0:9200 \
  --meta-endpoint http://meta1:9100 \
  --disks /dev/sdb,/dev/sdc,/dev/sdd
    Flag Default Purpose
    -c, --config <path> /etc/objectio/osd.toml TOML config file
    -l, --listen <addr> none gRPC listen — required; cluster convention is :9200
    --advertise-addr <addr> none How peers reach this OSD (falls back to listen)
    --disks <list> empty Explicit disk paths (comma-separated); disables discovery
    --disk-filter <glob> empty Discovery glob(s), e.g. /dev/disk/by-id/wwn-*; repeatable
    --disk-min-size <bytes> 1 GiB Lower bound for discovered disks
    --init-blank-disks off Allow discovery to format blank disks (off by default)
    --meta-endpoint <url> none Meta service
    --data-dir <path> none OSD metadata (WAL, object index)
    --metrics-port <n> 9201 Prometheus scrape port
    --log-level <lvl> info

    TOML¶

    # /etc/objectio/osd.toml
[osd]
listen = "0.0.0.0:9200"
meta_endpoint = "http://meta1:9100"

[osd.failure_domain]
region = "eu-west-1"
datacenter = "dc1"
rack = "rack1"

[storage]
disks = ["/dev/sdb", "/dev/sdc", "/dev/sdd"]
block_size = 4194304   # 4 MiB
data_dir = "/var/lib/objectio/osd"

[logging]
level = "info"

    Disk discovery vs explicit disks. --disks is the production path — list the devices this OSD owns. --disk-filter is for fleets where device names aren't stable (use by-id paths). Without --init-blank-disks, unformatted disks are skipped rather than claimed, as a guard against accidental data loss.

    objectio-block-gateway¶

    iSCSI / NBD / NVMe-oF target built on top of ObjectIO objects.

    objectio-block-gateway \
  --listen 0.0.0.0:9300 \
  --nbd-listen 0.0.0.0:10809 \
  --advertise-host block.internal \
  --meta-endpoint http://meta1:9100 \
  --data-dir /var/lib/objectio/block-gw
    Flag Default Purpose
    --listen <addr> 0.0.0.0:9300 BlockService gRPC listen
    --nbd-listen <addr> 0.0.0.0:10809 NBD TCP listen
    --advertise-host <host> empty Hostname used in NBD attachment URLs
    --meta-endpoint <url> http://localhost:9100
    --data-dir <path> ./block-gw-data Redb store + journal
    --cache-bytes <n> 268435456 Write-cache size (256 MiB)
    --flush-interval-s <n> 5 Background flush interval
    --ec-k <n> / --ec-m <n> 4 / 2 EC profile for chunk objects
    --log-level <lvl> info

    objectio-aio¶

    Single-process cluster (meta + OSD + gateway). See quickstart.md for the full usage.

    Flag Default Purpose
    --port <n> 9000 Public S3 / Iceberg / Delta / console port
    --listen-addr <ip> 0.0.0.0 Bind interface
    --data <dir> tempdir Persistent data root
    --osds <n> 1 Number of OSDs to spawn in-process
    --auth off Enable SigV4 on the gateway (admin AK/SK printed at startup)
    --admin-port <n> 0 (off) Mirror of objectio-gateway --admin-listen — bind admin API + /metrics to its own port.
    --ops-console-port <n> 0 (off) Mirror of --ops-console-listen — serve the ops SPA on its own port.
    --tenant-console-port <n> 0 (off) Mirror of --tenant-console-listen — serve the tenant SPA on its own port.
    --endpoint-name <name> empty Mirror of the gateway's --endpoint-name, for --port.
    --data-port <port>=<name> — Mirror of --data-listen on --listen-addr. Repeatable.
    --trusted-proxies <cidrs> empty Mirror of the gateway's --trusted-proxies.
    --audit-log <path> unset Mirror of the gateway's --audit-log.
    --log-level <lvl> info Honoured only if RUST_LOG is unset
    --strict-port off Fail on --port conflict instead of picking ephemeral

    Pass any of --admin-port / --ops-console-port / --tenant-console-port to test split-mode flows locally. The aio binary embeds both SPA bundles (ops + tenant) at compile time, so no separate console build is needed. With --strict-port set, all configured ports are checked for conflicts before launch.

    Example — local split-mode test:

    objectio-aio \
  --port 9000 \
  --admin-port 9001 \
  --ops-console-port 9002 \
  --tenant-console-port 9003 \
  --auth --strict-port \
  --data /tmp/objectio-aio

    Admin AK/SK are written to <data>/admin-creds.env on first start (keys AWS_ACCESS_KEY_ID and AWS_SECRET_ACCESS_KEY).

    objectio-install¶

    Node bootstrapper. See linux.md for a walkthrough.

    objectio-install init \
  --role all \
  --disks /dev/sdb,/dev/sdc,/dev/sdd \
  --ec-profile 4+2 \
  --systemd

objectio-install disk list
objectio-install disk prepare /dev/sdb
objectio-install disk check /dev/sdb

objectio-install join \
  --meta-endpoint http://meta1.internal:9100 \
  --disks /dev/sdb,/dev/sdc

objectio-install status

    init flags:

    Flag Default Purpose
    --role <list> required all, gateway, meta, osd (comma-separated)
    --disks <list> empty Disk devices for OSD roles
    --meta-endpoint <url> http://localhost:9001 Used by gateway + OSD roles
    --raft-peers <list> empty Meta-role peer list
    --ec-profile <k+m> 4+2 Common profiles: 2+1, 4+2, 8+4, 1+2 (3× replication)
    --no-auth off Bake no-auth into the generated gateway config
    --config-dir <dir> /etc/objectio Where config files land
    --systemd off Install + enable systemd units (requires root)
    --skip-prepare off Don't touch disks — just render config files
    --block-size-mb <n> 4 On-disk block size at format time

    Configuration precedence¶

    For every setting:

    1. CLI flag
    2. Environment variable (if the setting is in the env table above)
    3. TOML file value
    4. Built-in default

    So --log-level debug on the command line beats RUST_LOG=info, which beats [logging] level = "warn" in the TOML file.

    The meta raft-bootstrap Job and the Helm chart pass settings exclusively through CLI flags in the container command: — if you find yourself reaching for env vars in a compose file, check the list above first; many of the env vars that appear in deploy/local-cluster/docker-compose.yml are not actually read by the binaries.

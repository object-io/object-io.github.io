    Installation¶

    Everything you need to stand up ObjectIO — from a one-binary demo on a laptop to a production Kubernetes install.

    Start here¶

    Path Walkthrough Best for
    🚀 Fastest demo quickstart.md One binary or one container, <60 s to aws s3 ls
    🐧 Bare-metal Linux linux.md Production servers, systemd, raw disks
    🍏 macOS macos.md Dev laptops (AIO only — not a production target)
    🐳 Docker & Compose docker.md Local clusters, CI, single-host appliances
    ☸ Kubernetes kubernetes.md Helm chart, Kind demo, StatefulSet layout

    Platform support: Linux (amd64, arm64) and macOS (amd64, arm64) — both natively and in containers. ObjectIO is POSIX-only; there is no native Windows build.

    Deeper references¶

    • topologies.md — single-node vs rack-aware vs multi-DC; how many disks, nodes, and meta replicas you need for a given EC profile.
    • deployment-options.md — the detailed version: worked scenarios (1, 3, 6+ nodes), EC vs replication, configuration examples, capacity planning.
    • configuration.md — authoritative flag / env / TOML reference for every binary.

    Minimum requirements¶

    Component Minimum Recommended
    CPU 2 cores 8+ cores per OSD host
    RAM 4 GB 16+ GB (OSD), 8 GB (meta), 4 GB (gateway)
    Disk 1 × any block device or file 4+ raw disks per OSD, ≥ 1 TiB each
    Network 1 Gbps 10+ Gbps between OSDs
    Linux kernel 4.19+ 5.15+ (io_uring)
    macOS 12+ — (AIO dev only)
    Docker 24+ Buildx enabled for multi-arch
    Kubernetes 1.26+ With a WaitForFirstConsumer StorageClass

    Cluster sizing at a glance¶

    EC profile Min OSDs Recommended OSDs Meta replicas Survives
    4+2 6 7 (+1 spare) 3 2 disk / node failures
    8+4 12 14 3 or 5 4 failures
    10+4 LRC 14 15 5 4 failures, single-chunk repair
    replication=3 3 5 3 2 failures (3× overhead)

    Meta is a Raft cluster: use 1 pod for dev, 3 for prod, 5 for larger / geo-distributed clusters. Always odd.

    Default ports (cluster convention)¶

    Port Service Reachable from
    9000 Gateway — S3, Iceberg REST, Delta Sharing, /_console/, /_admin/ clients
    9100 Meta gRPC + Raft RPC internal
    9101 Meta Prometheus /metrics monitoring
    9102 Meta admin HTTP (Raft bootstrap / membership) operators
    9200 OSD gRPC internal
    9201 OSD Prometheus /metrics monitoring
    9300 Block gateway gRPC internal
    10809 Block gateway NBD target iSCSI / NBD initiators

    See configuration.md for the code defaults (which differ for meta and OSD) and how to override them.

    Security checklist (production)¶

    • [ ] TLS terminated in front of the gateway (ingress / LB / reverse-proxy).
    • [ ] Authentication enabled (--no-auth not set).
    • [ ] OIDC configured for the console + Iceberg JWTs, if applicable.
    • [ ] SSE master key present (gateway.sse.enabled: true in Helm).
    • [ ] Firewall / NetworkPolicy restricting 9100/9101/9200 to the internal network only.
    • [ ] Non-root objectio service user with CAP_SYS_RAWIO (not full root) on OSD nodes.
    • [ ] --trusted-proxies set to the ingress / load balancer network if TLS ends there and policies use aws:SecureTransport or aws:SourceIp.

    Bugs (3)¶

    1. test_object_content_encoding_aws_chunked: PutObject with Content-Encoding: gzip, aws-chunked and an ordinary body (normal SigV4 payload hash, not STREAMING-*) fails with 400 IncompleteBody "body ended before the terminal chunk". is_s3_chunked treats any aws-chunked in Content-Encoding as chunked framing, even when x-amz-content-sha256 is not STREAMING-*. Location: bin/objectio-gateway/src/chunked_decode.rs:23-31. The gzip and deflate, gzip steps of the test now pass (both failed in run 1).
    2. test_create_bucket_bucket_owner_preferred: CreateBucket with x-amz-object-ownership: BucketOwnerPreferred succeeds, and GetBucketOwnershipControls then answers BucketOwnerEnforced. The header is ignored without any error, while PutBucketOwnershipControls rejects the same value with InvalidRequest. create_bucket never reads the header: bin/objectio-gateway/src/s3.rs:2763 (compare put_ownership_controls, s3.rs:4586).
    3. test_create_bucket_object_writer: same as 2, with ObjectWriter.

    Gaps (4)¶

    1. test_bucket_list_return_data_versioning: ListObjectVersions <Version> entries have no <Owner>. AWS includes Owner (ID) there. ObjectVersionXml, bin/objectio-gateway/src/s3.rs:11693 (and DeleteMarkerXml at 11711).
    2. test_lifecycle_expiration_header_put: no x-amz-expiration header on PutObject when a lifecycle Expiration rule applies. Nothing in the gateway emits this header (no match for x-amz-expiration in bin/ or crates/). Rule evaluation is in bin/objectio-gateway/src/lifecycle.rs.
    3. test_lifecycle_expiration_header_head: same, on HeadObject.
    4. test_lifecycle_expiration_header_tags_head: same, for a tag-filtered rule on HeadObject.

    92 fixes that changed a test's result without making it pass:¶

    • Non-ASCII metadata: test_object_set_get_unicode_metadata used to fail with AccessDenied "invalid header value" on PUT. It now stores the value and returns it RFC 2047 encoded, which is what S3 does. The test, marked fails_on_rgw, wants the raw value.
    • gzip, aws-chunked: test_object_content_encoding_aws_chunked used to fail at its first step (gzip not returned). The first two steps now pass and it fails at the third (bug 1 above).
    • DELETE on unhandled sub-resources: test_bucket_create_delete_bucket_ownership used to fail with NoSuchBucket, because DELETE ?ownershipControls deleted the bucket. Now the DELETE is refused (InvalidRequest, ownership cannot be removed) and the bucket survives. It still fails because ObjectIO supports only BucketOwnerEnforced, by design.
    • The aws-chunked IncompleteBody handling and the DELETE-in-own-task change have no dedicated s3-tests test.
